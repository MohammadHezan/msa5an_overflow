# Jeeny reference assets

This Campus Connect hackathon prototype presents a proposed feature inside Jeeny. It is not connected to live Jeeny bookings or payments.

- `logo.svg`: Jeeny official website navigation logo, https://www.jeeny.me/static/images/v2/Layer%202.svg
- `favicon.png`: Jeeny official website icon, https://www.jeeny.me/static/images/v2/favicons.png
- Design references: official Jeeny passenger App Store listing, https://apps.apple.com/us/app/jeeny-book-affordable-rides/id1178701124

The screenshot references under `attached_assets/jeeny-reference/` are research material, not app screens or functional maps. Any schematic map created for the prototype is illustrative.
