Matching rules

  • Same direction. Students heading the same way share one car and meet at that direction's gate.
  • Same time. Classes in one car end within {{ rules.gap }} minutes of each other. Pickup is {{ rules.walk }} minutes after the last class ends.
  • Up to {{ rules.seats }} students per car, using as few cars as possible.
  • Who you ride with. Each student picks Anyone, Women only or Men only. A women-only request only shares with women students, a men-only request only with men; Anyone accepts everyone.
  • Friends ride together. A friends group (code like GR-48, up to {{ rules.seats }}) always gets one car. If they close empty seats, no one else joins.
  • Seat hold. After matching, each student has {{ rules.hold_minutes }} minutes to confirm a shared seat. Otherwise the seat is released and the car re-planned.
  • Fair split. Each car is one regular Jeeny ride at the regulated app fare: JOD {{ "%.3f" | format(rules.base / 1000) }} + JOD {{ "%.3f" | format(rules.per_km / 1000) }}/km over the whole route. Each student pays in proportion to their own distance, the shares add up to exactly that fare, and a student only shares a car if they save at least {{ rules.min_saving }}% compared with riding alone.
